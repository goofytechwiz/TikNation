Safe recovery checklist

  • Check service status and error logs first.
  • For messages, check delivery metadata—not message contents by default.
  • For gifts, verify transaction IDs and ledger events before any correction.
  • Never ask for passwords or one-time codes.
  • Require authorization and an audit log for every admin action.
  • Escalate suspected fraud, account takeover, or safety threats.
Before launch: connect Supabase Auth, enforce admin roles in server-side policies, and create protected ticket/ audit tables. A hidden page alone is not security.
